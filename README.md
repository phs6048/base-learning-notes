# base-learning-notes

Base 프로젝트를 시작하기 전 필요한 Git 기초를 연습하는 한국어 노트 모음입니다.
AI의 도움으로 작성한 참고 자료이며, 작성자가 각 실습을 완료했다는 기록은 아닙니다.

## 사용법

각 노트는 목적, 명령어, 관찰 과제로 구성되어 있습니다. 독립적인 참고 카드이며,
위에서부터 모든 명령을 무조건 실행하는 스크립트가 아닙니다.
쓰기 명령은 실제 프로젝트가 아닌 별도의 `practice-repo`에서 연습하세요.
예제 파일·브랜치·원격이 먼저 있어야 하는 명령은 해당 준비를 한 뒤 실행합니다.
Git이 설치된 터미널에서 명령을 한 줄씩 실행하고 결과를 읽으세요.
명령 출력은 저장소 상태와 Git 버전에 따라 달라집니다.
작성자·설정·원격 URL 출력에 비공개 정보가 있으면 공개 문서에 붙여 넣지 마세요.

## 자료

- [Git 공식 튜토리얼](https://git-scm.com/docs/gittutorial)
- [Git 명령어 매뉴얼](https://git-scm.com/docs)
- [Base 개발자 문서](https://docs.base.org/)
- [Base Build](https://www.base.org/build)

이 저장소의 커밋 수와 외부 길드의 기여도 집계는 별도 기준일 수 있습니다.
롤 및 보상 인정 여부는 해당 서비스에서 확인하세요.
