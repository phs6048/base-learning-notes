# 030. 커밋 개수 세기

분류: 이력

## 목적

HEAD에서 도달 가능한 커밋 개수를 센다.

## 명령어

```sh
git rev-list --count HEAD
```

## 관찰 과제

저장소 커밋 수와 외부 서비스의 개인 기여 집계가 같다고 단정할 수 없는 이유를 적으세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
