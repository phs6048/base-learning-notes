# 021. 최근 다섯 커밋

분류: 이력

## 목적

최근 커밋 다섯 개까지 짧은 식별자와 제목으로 보여준다.

## 명령어

```sh
git log -5 --oneline
```

## 관찰 과제

커밋이 다섯 개보다 적을 때 출력 개수를 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
