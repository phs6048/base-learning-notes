# 036. 단어 단위 비교

분류: 변경 비교

## 목적

줄 안에서 달라진 부분을 단어 단위로 표시한다.

## 명령어

```sh
git diff --word-diff
```

## 관찰 과제

한 줄의 단어 하나를 바꾸고 일반 diff와 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
