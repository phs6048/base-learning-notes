# 056. 원격 정보 가져오기

분류: 원격

## 목적

원격 객체와 참조 정보를 가져오며 현재 작업 브랜치에는 자동 병합하지 않는다.

## 명령어

```sh
git fetch origin
```

## 관찰 과제

fetch 이후 작업 파일이 그대로인지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
