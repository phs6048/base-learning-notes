# 070. 줄별 마지막 변경 이력

분류: 검색

## 목적

지정 줄 범위를 마지막으로 변경한 커밋과 작성자를 보여준다. 파일에 다섯 줄 이상 필요하다.

## 명령어

```sh
git blame -L 1,5 -- README.md
```

## 관찰 과제

사람을 평가하는 대신 변경 이유를 추적하는 단서로 활용해 보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
