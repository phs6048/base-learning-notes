# 007. 현재 브랜치 이름

분류: 환경과 상태

## 목적

현재 브랜치 이름을 출력하며 분리된 HEAD에서는 비어 있을 수 있다.

## 명령어

```sh
git branch --show-current
```

## 관찰 과제

일반 브랜치와 분리된 HEAD의 차이를 설명해 보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
