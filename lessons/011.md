# 011. 실습 저장소 초기화

분류: 스테이징

## 목적

main을 초기 브랜치 이름으로 사용하는 새 저장소 폴더를 만든다.

## 명령어

```sh
git init -b main practice-repo
```

## 관찰 과제

학습 저장소 밖의 별도 폴더에서 만들고 이후 예제는 그 안에서 진행하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
