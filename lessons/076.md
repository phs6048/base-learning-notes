# 076. 전체 트리 파일 경로

분류: 객체

## 목적

커밋 트리 안의 파일 경로를 재귀적으로 나열한다.

## 명령어

```sh
git ls-tree -r --name-only HEAD
```

## 관찰 과제

작업 폴더의 추적되지 않은 파일이 포함되는지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
