# 017. 스테이징 취소

분류: 스테이징

## 목적

HEAD가 있는 저장소에서 해당 파일을 HEAD 기준으로 인덱스에서 되돌린다. 작업 파일 내용은 유지한다.

## 명령어

```sh
git restore --staged notes.md
```

## 관찰 과제

실습용 변경을 추가한 뒤 실행하고 수정 내용이 남아 있는지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
