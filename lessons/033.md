# 033. 변경 파일 이름만 보기

분류: 변경 비교

## 목적

작업 폴더와 인덱스 사이에서 차이가 나는 파일 경로만 출력한다.

## 명령어

```sh
git diff --name-only
```

## 관찰 과제

파일 내부 내용 대신 경로만 필요할 때를 생각해 보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
