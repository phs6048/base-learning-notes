# 006. 브랜치까지 상태 요약

분류: 환경과 상태

## 목적

간단한 파일 상태 위에 브랜치 정보를 함께 출력한다.

## 명령어

```sh
git status --short --branch
```

## 관찰 과제

브랜치 줄과 파일 줄을 구별하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
