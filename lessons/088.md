# 088. 참조별 서식 출력

분류: 참조

## 목적

로컬 브랜치 이름과 참조 대상의 객체 종류를 지정 서식으로 출력한다.

## 명령어

```sh
git for-each-ref --format="%(refname:short) %(objecttype)" refs/heads
```

## 관찰 과제

스크립트에서 서식을 고정하면 어떤 점이 편한지 설명하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
