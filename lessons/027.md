# 027. 작성자로 이력 찾기

분류: 이력

## 목적

작성자 이름이나 이메일이 패턴과 일치하는 커밋을 찾는다.

## 명령어

```sh
git log --oneline --author=phs6048
```

## 관찰 과제

다른 작성자가 있는 저장소라면 전체 목록과 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
