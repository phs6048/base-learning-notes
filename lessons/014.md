# 014. 추적 파일 변경 반영

분류: 스테이징

## 목적

이미 추적 중인 파일의 수정과 삭제를 인덱스에 반영한다.

## 명령어

```sh
git add -u
```

## 관찰 과제

새 파일 하나와 기존 파일 수정을 준비하고 새 파일이 추가되지 않는지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
