# 037. 공백 차이 무시

분류: 변경 비교

## 목적

공백의 차이를 무시해 변경을 비교한다.

## 명령어

```sh
git diff --ignore-all-space
```

## 관찰 과제

의미 있는 공백이 있는 코드에서는 이 옵션만 믿으면 안 되는 이유를 적으세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
