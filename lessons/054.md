# 054. 푸시 대상 URL

분류: 원격

## 목적

origin에 설정된 push URL을 보여준다.

## 명령어

```sh
git remote get-url --push origin
```

## 관찰 과제

fetch 주소와 push 주소가 다른 구성이 가능한지 설명하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
