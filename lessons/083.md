# 083. 태그 목록

분류: 참조

## 목적

태그 이름을 나열한다. 태그가 없으면 출력이 비어 있다.

## 명령어

```sh
git tag --list
```

## 관찰 과제

빈 결과를 오류로 오해하지 않고 설명하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
