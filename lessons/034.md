# 034. 변경 유형 표시

분류: 변경 비교

## 목적

HEAD와 비교한 변경 파일 경로와 수정 및 삭제 같은 상태를 보여준다.

## 명령어

```sh
git diff --name-status HEAD
```

## 관찰 과제

수정된 파일과 삭제된 파일의 표시를 구분하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
