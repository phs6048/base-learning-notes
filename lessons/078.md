# 078. 파일 내용 해시 계산

분류: 객체

## 목적

파일 내용을 blob으로 표현할 때의 식별자를 계산하며 기본적으로 저장하지 않는다.

## 명령어

```sh
git hash-object README.md
```

## 관찰 과제

파일 내용 한 글자를 바꾸고 식별자를 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
