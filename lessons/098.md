# 098. 읽기 전용 저장소 검사

분류: 검토와 공유

## 목적

객체 연결과 무결성을 검사한다. 도달 불가능한 객체 보고가 곧 손상을 뜻하지는 않는다.

## 명령어

```sh
git fsck --full
```

## 관찰 과제

오류와 단순 dangling 보고를 구분하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
