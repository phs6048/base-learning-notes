# 077. 커밋 속 README 읽기

분류: 객체

## 목적

HEAD 트리에 저장된 README.md 내용을 출력한다.

## 명령어

```sh
git show HEAD:README.md
```

## 관찰 과제

작업 파일을 수정한 후 두 내용을 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
