# 009. 로컬 설정 살펴보기

분류: 환경과 상태

## 목적

현재 저장소에 적용되는 로컬 설정을 나열한다.

## 명령어

```sh
git config --local --list
```

## 관찰 과제

출력에 인증 관련 값이 있다면 공유하지 말고 항목 이름만 살펴보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
