# 029. 파일 변경 통계와 이력

분류: 이력

## 목적

최근 커밋별 변경 파일과 줄 수 요약을 보여준다.

## 명령어

```sh
git log -3 --stat
```

## 관찰 과제

가장 많은 파일을 바꾼 커밋과 실제 변경 범위를 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
