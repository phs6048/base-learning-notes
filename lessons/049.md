# 049. 포함된 브랜치 찾기

분류: 브랜치

## 목적

현재 커밋을 조상으로 포함하는 로컬 브랜치를 보여준다.

## 명령어

```sh
git branch --contains HEAD
```

## 관찰 과제

새 커밋 전후로 목록이 어떻게 바뀌는지 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
