# 094. 파일 추가 기록 확인

분류: 검토와 공유

## 목적

지정 경로가 추가된 변경을 포함한 이력을 찾는다.

## 명령어

```sh
git log --diff-filter=A --oneline -- README.md
```

## 관찰 과제

파일이 처음 등장한 커밋을 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
