# 055. 서버 브랜치 조회

분류: 원격

## 목적

서버가 광고하는 브랜치 참조와 식별자를 읽는다. 네트워크가 필요하다.

## 명령어

```sh
git ls-remote --heads origin
```

## 관찰 과제

로컬 원격 추적 브랜치와 서버의 값을 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
