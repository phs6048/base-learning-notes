# 089. 커밋의 첫 부모

분류: 참조

## 목적

현재 커밋의 첫 부모 식별자를 출력한다. 루트 커밋에는 부모가 없다.

## 명령어

```sh
git rev-parse "HEAD^"
```

## 관찰 과제

부모가 있는 실습 저장소에서 log의 이전 커밋과 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
