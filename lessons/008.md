# 008. 설정 출처 확인

분류: 환경과 상태

## 목적

작성자 이름 설정이 지정된 위치와 값을 보여준다. 미설정이면 값이 없다.

## 명령어

```sh
git config --show-origin --get user.name
```

## 관찰 과제

값이 저장소 설정인지 사용자 설정인지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
