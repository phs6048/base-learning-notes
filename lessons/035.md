# 035. 줄 단위 변경 통계

분류: 변경 비교

## 목적

파일별 추가 줄 수와 삭제 줄 수를 기계적으로 읽기 쉬운 형태로 출력한다.

## 명령어

```sh
git diff --numstat HEAD
```

## 관찰 과제

바이너리 파일에서는 숫자 대신 다른 표식이 쓰일 수 있음을 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
