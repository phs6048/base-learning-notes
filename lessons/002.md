# 002. 저장소 루트 찾기

분류: 환경과 상태

## 목적

현재 작업 위치가 속한 저장소의 최상위 경로를 출력한다.

## 명령어

```sh
git rev-parse --show-toplevel
```

## 관찰 과제

하위 폴더에서 실행해도 같은 루트 경로가 나오는지 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
