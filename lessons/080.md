# 080. 객체 저장 통계

분류: 객체

## 목적

느슨한 객체 수와 팩 파일 관련 저장 통계를 보여준다.

## 명령어

```sh
git count-objects -v
```

## 관찰 과제

작업 폴더 크기와 같은 의미인지 구별하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
