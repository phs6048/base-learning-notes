# 050. 이미 합쳐진 브랜치 확인

분류: 브랜치

## 목적

브랜치 끝 커밋이 HEAD에서 도달 가능한 로컬 브랜치를 보여준다.

## 명령어

```sh
git branch --merged HEAD
```

## 관찰 과제

삭제하지 말고 어떤 브랜치가 현재 이력에 포함됐는지만 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
