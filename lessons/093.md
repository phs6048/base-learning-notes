# 093. 파일별 추가 삭제 요약

분류: 검토와 공유

## 목적

최근 커밋 제목과 파일별 추가 및 삭제 줄 수를 보여준다.

## 명령어

```sh
git show --numstat --format=oneline HEAD
```

## 관찰 과제

검토할 파일의 우선순위를 정하고 실제 diff도 읽으세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
