# 068. 문자열 등장 변화 찾기

분류: 검색

## 목적

diff에서 해당 문자열의 출현 횟수가 달라지는 커밋을 찾는다.

## 명령어

```sh
git log --oneline -S"README"
```

## 관찰 과제

문자열이 유지되는 단순 이동과 추가의 차이를 생각해 보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
