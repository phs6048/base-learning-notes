# 010. 추적 파일 확인

분류: 환경과 상태

## 목적

인덱스에서 추적 중인 파일 경로를 나열한다.

## 명령어

```sh
git ls-files
```

## 관찰 과제

디렉터리에 있지만 목록에는 없는 파일이 있는지 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
