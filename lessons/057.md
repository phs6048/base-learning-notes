# 057. 네트워크 없이 원격 정보

분류: 원격

## 목적

서버에 묻지 않고 로컬에 있는 원격 정보를 보여준다.

## 명령어

```sh
git remote show -n origin
```

## 관찰 과제

실시간 서버 상태와 다를 수 있는 이유를 적으세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
