# 064. 문자 그대로 검색

분류: 검색

## 목적

정규식 대신 지정한 문자열 자체를 검색한다.

## 명령어

```sh
git grep -n -F "git status"
```

## 관찰 과제

공백이 포함된 문구를 따옴표로 감싸는 이유를 설명하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
