# 005. 스크립트용 상태 형식

분류: 환경과 상태

## 목적

프로그램에서 사용하기 위한 안정적인 상태 형식을 출력한다.

## 명령어

```sh
git status --porcelain=v1
```

## 관찰 과제

일반 status의 설명 문구 없이 파일 상태를 읽어보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
