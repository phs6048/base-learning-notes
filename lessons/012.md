# 012. 단일 파일 추가

분류: 스테이징

## 목적

지정한 파일의 현재 내용을 인덱스에 반영한다.

## 명령어

```sh
git add README.md
```

## 관찰 과제

실습용 README.md를 만든 후 추가하고 status로 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.

## 다음 단계

[전체 목차](../README.md)에서 관련 주제를 선택하세요.
명령의 자세한 옵션은 [Git 공식 매뉴얼](https://git-scm.com/docs)에서 확인할 수 있습니다.
