# 073. 커밋 원문 읽기

분류: 객체

## 목적

커밋 객체의 tree와 parent 및 작성자 등의 정보를 읽는다.

## 명령어

```sh
git cat-file -p HEAD
```

## 관찰 과제

작업 파일 내용이 커밋 객체 본문에 직접 들어 있는지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
