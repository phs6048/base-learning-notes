# 095. 이름 변경 추적

분류: 검토와 공유

## 목적

단일 파일의 이력을 이름 변경 너머까지 추적하도록 요청한다. 감지는 유사도 등에 영향을 받는다.

## 명령어

```sh
git log --follow --oneline -- README.md
```

## 관찰 과제

별도 실습 브랜치에서 이름을 바꾼 파일로 동작을 관찰하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
