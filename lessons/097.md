# 097. 첫 부모 흐름 읽기

분류: 검토와 공유

## 목적

병합 시 첫 부모를 따라 이력의 주 흐름을 읽는다.

## 명령어

```sh
git log --first-parent --oneline -10
```

## 관찰 과제
