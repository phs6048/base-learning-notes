# 040. 마지막 커밋 전후 비교

분류: 변경 비교

## 목적

부모 커밋과 현재 커밋의 파일 트리 차이를 보여준다. 부모가 있어야 실행할 수 있다.

## 명령어

```sh
git diff HEAD~1 HEAD
```

## 관찰 과제

커밋 두 개 이상인 실습 저장소에서 최근 변경을 설명해 보세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
