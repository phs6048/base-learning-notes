# 069. 줄 변경 패턴 찾기

분류: 검색

## 목적

패턴에 맞는 추가 또는 삭제 줄이 있는 커밋을 경로 내에서 찾는다.

## 명령어

```sh
git log --oneline -G"^#" -- README.md
```

## 관찰 과제

헤딩을 고친 커밋을 찾아 S 옵션과 목적을 비교하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
