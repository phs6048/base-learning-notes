# 015. 변경 파일 경로 미리보기

분류: 스테이징

## 목적

현재 폴더 아래에서 추가될 항목을 실제 추가 없이 보여준다.

## 명령어

```sh
git add --dry-run .
```

## 관찰 과제

실행 전후 status가 동일한지 확인하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
