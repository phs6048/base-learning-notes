# 100. 업로드 전 검토 순서

분류: 검토와 공유

## 목적

현재 브랜치와 남은 변경을 다시 확인한다.

## 명령어

```sh
git status --short --branch
```

## 관찰 과제

status, 마지막 커밋 diff, 작성자, 원격 주소를 차례로 확인한 뒤 필요한 경우에만 push하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
