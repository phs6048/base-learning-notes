# 047. 원격 추적 브랜치 목록

분류: 브랜치

## 목적

로컬에 저장된 원격 추적 브랜치를 나열한다.

## 명령어

```sh
git branch -r
```

## 관찰 과제

이 목록이 서버를 실시간 조회하는 것은 아니라는 점을 설명하세요.

실행 결과를 직접 읽고 답을 적어보세요. 이 문서는 실습 완료 기록이 아닙니다.
쓰기 명령은 별도 실습 저장소에서 사용하고, 필요한 파일·브랜치·원격을 먼저 준비하세요.
